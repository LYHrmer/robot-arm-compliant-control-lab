# 姿态新增益能否用于原 24-case 网格

上一轮[停顿换向对照](rotation_gain_comparison.md)中，统一采用两倍旋转刚度和
平方根二倍旋转阻尼，使在线补偿的阶段检查从 40/42 变为 42/42。不过那轮固定了
一个几何配置。本页补查原来的表面方向与工具质量组合，增益仍只比较 $s=1$ 和 $s=2$。

## 结果与采用决定

192 次运行全部通过本轮工程检查；旧增益的 96 行、13 项既有指标逐项复现，最大差值为 0。
但新增益没有全面改善跟踪。在线方法在全部 24 个 case 中降低姿态误差，也在全部
24 个 case 中增加切向位置和速度误差，12 个物理组合的两个种子均呈现这一取舍。

| 在线方法指标 | 原 $s=1$ | 新 $s=2$ |
|---|---:|---:|
| 姿态 RMSE 中位数 [°] | 0.4643 | 0.2483 |
| 切向位置 RMSE 中位数 [mm] | 1.3590 | 1.4093 |
| 切向速度误差 RMS 中位数 [mm/s] | 4.1401 | 4.6350 |
| 法向力 RMSE 中位数 [N] | 0.1719 | 0.1812 |
| 全部运行中的最大原始接触力 [N] | 12.6992 | 12.6915 |
| 全部运行中的最小预留包络余量 [N·m] | 4.6652 | 4.6662 |

同 case 的切向位置 RMSE 增量为 0.0413–0.0560 mm，速度误差 RMS 增量为
0.4387–0.5135 mm/s。按 24 次运行的均值计算，姿态误差下降 46.24%，切向位置误差
增加 3.48%，速度误差增加 11.26%；这些百分比使用均值，不能拿上表的中位数直接相除。
法向力 RMSE 的单 case 最大增加为 0.01035 N。没有发生执行器裁剪或力矩投影缩放。

代价并非由某个噪声种子造成。在线方法在 +15° 的四个物理组合中切向退化最明显，
两个种子的平均位置增量约 0.0545–0.0549 mm，速度增量约 0.506–0.508 mm/s；
该方向的姿态改善也最小，约 0.2005°。质量和接触时间常数变化没有引出额外的明显失效。
各方法首次原始接触还比旧增益晚 2–4 ms，配对表中保留了这个变化。

本轮决定：**全局默认值保持 $s=1$，不改成 $s=2$。** 速度代价在所有 case 中重复出现，
不能用姿态改善抵消后只给一个总分。对更重视姿态保持的仿真实验，可显式使用 $s=2$；
默认 $s=1$ 和原 BC/PPO 基线不变。这是任务需求下的取舍，未另设一个事后百分比门槛。

[全部 192 行](../results/franka_rotation_gain_public24/comparison.csv)、
[逐 case 配对差值](../results/franka_rotation_gain_public24/paired.csv)与
[12 个物理组合的分组统计](../results/franka_rotation_gain_public24/summary.json)均保留。
这轮是公开开发回归，不构成新的未见场景证据。

## 覆盖的范围

| 因素 | 固定取值 | 能说明什么 |
|---|---|---|
| 表面、任务及控制器偏航角 | −15°、0°、15°，三者始终一致 | 不同表面方向和机械臂运动路径；未测试法向标定误差 |
| 接触时间常数 | 0.005、0.012 s | 两档平滑接触配置；不能当作真实材料辨识 |
| 工具质量 | 0.10、0.13 kg | 质量已进入动力学模型，未测试未知负载 |
| 测量噪声种子 | 11、29 | 每个物理组合重复两次，未增加独立物理场景 |

共 12 个物理组合 × 2 个噪声种子。四种方法在两套增益下都运行，合计 192 次仿真。
单次仍为 4.5 s，评价从 1.5 s 开始；摩擦系数固定 0.45，法向目标力为 12 N。
平移增益和原来的接触模型没有改变。

这里的“不同方向”需要说清楚。工具的目标旋转始终取 home 初始姿态；变化的是墙面和
擦拭轨迹方向，机械臂因此走过不同的关节状态与 Jacobian。不能写成已经验证了任意
目标 pitch/roll，也没有在这轮加入换向或动态摩擦。长时误差实验的结论要另看。

## 配对与检查

先将 $s=1$ 的全部 96 行与
[原回归](../results/franka_online_compensation_regression/comparison.csv)比较，要求原有
13 项数值指标的最大绝对差不超过 `1e-10`，在线方法的 24 行也包含在内。
随后用同方法、同 case 和同种子计算 $s=2-s=1$ 的差值。
在线与固定前馈之间的比较则在同一增益下进行，不能拿新增益的在线方法减去旧增益前馈。

本轮统一报告接触率 ≥99%、完整轨迹原始峰值力 ≤35 N、执行器裁剪为 0，
以及法向力／姿态 RMSE 相对同增益固定前馈增加不超过 0.2 N／0.2°。
同时要求投影比例统计为 0、预留力矩包络余量非负，这两项数值容差为 `1e-10`。
配对力和姿态门槛沿用原函数的 `1e-12` 舍入余量。
这是本次开发对照的工程检查，不会追认成旧实验中所有方法的预注册门槛。

每种方法分别保存位置和速度误差的配对变化。通过上述检查不代表两种跟踪误差都改善，
也没有根据跑出的结果追加一个宽松的“允许退化百分比”。

### 力矩余量怎么算

设第 $j$ 个关节的物理力矩区间为 $[l_j,u_j]$，请求力矩为 $\tau_j$。
每次运行的物理余量取全部周期、全部关节中离最近边界的最小距离：

$$h_{physical}=\min_{k,j}\{\tau_j[k]-l_j[k],\ u_j[k]-\tau_j[k]\}.$$

控制器原来预留了总区间宽度的 10%，均分到两侧。令

$$r_j=0.05(u_j-l_j),$$

则预留包络的余量为

$$h_{reserved}=\min_{k,j}\{\tau_j[k]-(l_j[k]+r_j[k]),\ (u_j[k]-r_j[k])-\tau_j[k]\}.$$

两项都使用未裁剪的请求力矩，单位 N·m；计算区间包含入触过程。负值表示请求超出
对应包络。投影比例为零只说明没有发生缩放，不能代替这个距离指标。
最小余量仍是仿真中的记录值，不能据此选定真机安全余量。

## 运行与复核

在仓库根目录、安装开发依赖后执行。输出目录必须不存在：

```bash
python -m tools.rotation_gain_regression --output /tmp/rotation-public24

# 不运行新动力学，独立重算所有紧凑轨迹指标及配对结论
python -m tools.audit_rotation_gain_regression --audit /tmp/rotation-public24

# 复核仓库中已发布的实验
python -m tools.audit_rotation_gain_regression --audit results/franka_rotation_gain_public24
```

快速检查可加 `--case-indices 0`，运行八次，但子集结果不会冒充完整 24-case。
协议会在仿真前写入暂存目录；运行中源码或固定参考归档改变，会拒绝发布结果。

所有运行保留紧凑指标输入，包括真实位置与目标、角度误差、原始接触力和未裁剪力矩。
每份轨迹还带自身的增益、方法与 case 索引。额外完整保留预选 case 0、16、23 的
固定前馈及在线方法，两套增益共 12 份完整轨迹，可用现有 Python 控制器回放。
这些是记录输入回放，未在 C++ 中重新运行机械臂动力学。

`paired.csv` 保留 96 个同方法配对。`summary.json` 另按表面方向、接触时间常数和质量的
联合取值汇总两个噪声种子，避免只报一个总平均数。完整配置位于 `protocol.json`，
来源哈希和逐文件清单位于 `source_hashes.json`、`manifest.json`。

独立审计会重算全部 16 项指标，检查完整轨迹与对应紧凑轨迹一致，并拒绝修改配对表后
重新计算哈希的伪造摘要。来源必须匹配当前生成器，或审计器中已固定的历史来源摘要；
实验目录不能自行声明一个陌生来源后就获得信任。

后续另做了[36 次跨方向动态回归](cross_surface_regression.md)，把原有停顿换向和组合误差
迁移到 −15°、0°。新增方向未出现额外工程阶段失效，跟踪代价和后段残余误差仍保留；
这份 192 次短时归档没有修改，也不与后续单种子 12 秒结果合并计算。

预选的 12 份完整轨迹另完成了 27,000 步 Python/C++ 数值回放。Python 重算与保存命令
完全一致，C++ wrench／关节力矩最大分量差均为 `3.5527136788e-15`。
[回放报告](../results/franka_rotation_gain_public24_cpp/report.json)保存逐轨迹结果；
其中独立耗时 benchmark 仍使用原默认参数，不是真机或这组姿态预设的实时性测量。

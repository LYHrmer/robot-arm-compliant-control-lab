# 换向恢复：有入口上限的可逆回退

本页记录一个公开开发试验。运行前先固定规则和门槛；默认固定 6 N、姿态增益 1、
速度误差时间系数 0.05 s 均不变。六轴项目和 BC/PPO 不在本轮范围内。

结果：小试 **4/4**，完整回归 **32/36，整体 `FAIL`**。原来的两个高负载反例得到改善，
但 +15° 降载叠加组合误差新增四条速度代价失败。不能据此替换旧方法或默认配置。

## 要检验的机制

[上一轮静止回退](stationary_recovery_pilot.md)通过 3/4，整体仍为 `FAIL`。
它把回退推迟到目标静止，两个高负载种子都改善，但 seed 29 仍超原代价上限。
控制器小例子还显示，法向力的短时峰值会给只降不升的系数留下记忆。

这里的系数 $\mu$ 是误差驱动的等效补偿状态，不能直接解释为辨识出的材料摩擦系数。
目标静止时没有切向运动激励，法向力恢复也不能证明材料摩擦变大。
本轮检验的是内部限幅状态的恢复策略，不增加摩擦观测器。

## 唯一算法改动

进入一次有效接触下的目标静止阶段时，记录当时的 $\mu$ 为上限 $\mu_h$。
保持期间使用

$$
\mu^*_k=\min\left(\mu_h,\frac{B_k}{F_{n,k}}\right),\qquad
\mu_{k+1}=\mu_k+\operatorname{clip}
\left(\mu^*_k-\mu_k,-r_\mu\Delta t,r_\mu\Delta t\right).
$$

$B_k$ 是本拍补偿预算，$F_{n,k}>1$ N 是修正法向力。
速率 $r_\mu=0.3$/s 沿用原值，系数不高于本次保持入口值，也不越过原绝对范围。
没有新调参项。若整个保持阶段的法向力和预算均不变，该规则与旧静止回退应给出相同结果。

目标切向速度不超过 $10^{-12}$ m/s 才视作数值零。缺少有效测量包或力矩投影拒绝更新时，
只冻结本次更新，不重新记录入口上限。目标恢复运动、接触失效或控制器重置时清除入口记录。
控制器不读取仿真时间、运动阶段标签或真实摩擦参数。

原运动学习律、50 ms 运动确认、20 N/s 补偿力变化率以及 6–8 N 调度均保持不变。
本协议固定运动更新阈值为 0.005 m/s，高于数值零阈值；保持期间父类学习更新因此关闭。
本文不把这一性质推广到任意自定义更新阈值。
这仍是限幅回退候选，未采用为默认控制器，也未完成 C++ 移植。

## 执行前固定的范围

先运行 −15°、无额外误差下的降载／恒定高负载两种场景，每种使用种子 11、29。
新候选执行 4 次；原调度、旧回退和上一轮静止回退共 12 条轨迹原位引用。
16 条方法轨迹只对应两个物理场景，不是 16 个独立场景。

主要门槛继续按新候选对原调度逐例比较：降载的 8–10 s 和 8–12 s 位置 RMSE 各降低
至少 10%；其余窗口位置增量不超过 0.1 mm；各窗口速度误差增量不超过 0.5 mm/s。
原法向力、姿态、峰值和绝对工程门槛不变。
另外要求两个高负载种子的 7–8 s 位置、速度 RMSE 都严格低于上一轮静止回退。
不能用平均改善覆盖某个配对失败。

只有小试完整通过，才执行已固定的扩展矩阵：表面方向 −15°／0°／15°，
降载／恒定高负载，原有三种误差配置，以及种子 11、29，共 36 个配对。
其中 4 条新候选沿用小试轨迹，仅新增其余 32 条；另外引用 72 条旧方法轨迹，
总计评价 108 条。扩展矩阵仍不包含新载荷、俯仰、缺包组合或真机实验。

新候选对原调度在 5.5 s 前所有逐拍字段必须逐字节相同。
扩展时，幅值误差与对应无幅值误差的候选还须通过 6 s 前的输入错误前缀检查。
复算器独立重建辅助状态方程，不宣称独立复现整个名义控制器或机械臂动力学。

## 实测结果与决定

实现和两级协议先冻结在提交 `648d3e280263664bd45ee04d388e0e32d5834daa`，然后执行 4 条小试。
完整重算为 `PASS` 后，按原协议新增 32 条扩展轨迹，运行期间没有改源码或参数。
[小试归档](../results/franka_reversible_recovery_pilot/comparison.json)评价 16 条方法轨迹；
[扩展归档](../results/franka_reversible_recovery_transfer/comparison.json)评价 108 条，
其中 76 条是旧基线、旧候选和本次小试的原位引用，不是新增仿真。
36 个配对覆盖六个表面方向／负载组合、三种误差配置和两个噪声种子，不是 36 个独立物理场景。

### 小试改善了什么

下表均为高负载 7–8 s 相对原 6–8 N 调度的 RMSE 增量，**不是绝对 RMSE，也不是相对默认 6 N**。
两个种子的两项误差都严格低于上一轮静止回退，并通过 +0.1 mm／+0.5 mm/s 的原门槛。

| 种子 | 静止回退位置增量 mm | 可逆回退位置增量 mm | 静止回退速度增量 mm/s | 可逆回退速度增量 mm/s |
|---:|---:|---:|---:|---:|
| 11 | +0.095464 | +0.020051 | +0.458643 | +0.098050 |
| 29 | +0.106956 | +0.033753 | +0.545732 | +0.163723 |

这不意味着小试中的全部指标都改善。降载 seed 11 的 7–8 s 速度增量为 +0.418152 mm/s，
比上一轮静止回退多 +0.173405 mm/s，距离门槛只剩 0.081848 mm/s。

### 跨方向回归在哪里失败

每格是两个噪声种子分别检查后的通过数。误差定义沿用[原扩展协议](reversal_recovery_transfer.md)。

| 表面方向 | 误差配置 | 降载 | 恒定高负载 |
|---|---|---:|---:|
| −15° | 无额外误差 | 2/2 | 2/2 |
| −15° | 组合误差 | 2/2 | 2/2 |
| −15° | 组合误差＋辅助力幅值 ×0.8 | 2/2 | 2/2 |
| 0° | 无额外误差 | 2/2 | 2/2 |
| 0° | 组合误差 | 2/2 | 2/2 |
| 0° | 组合误差＋辅助力幅值 ×0.8 | 2/2 | 2/2 |
| +15° | 无额外误差 | 2/2 | 2/2 |
| +15° | 组合误差 | 0/2 | 2/2 |
| +15° | 组合误差＋辅助力幅值 ×0.8 | 0/2 | 2/2 |

降载合计 **14/18**，高负载 **18/18**。四条失败都只触发 7–8 s 的速度代价门槛：

| +15° 降载误差配置 | seed 11 速度增量 mm/s | seed 29 速度增量 mm/s |
|---|---:|---:|
| 组合误差 | +0.635332 | +0.643327 |
| 组合误差＋辅助力幅值 ×0.8 | +0.635459 | +0.643180 |

原上限为 +0.5 mm/s；最差超出 0.143327 mm/s。18 条降载配对的 8–10 s 位置收益仍为
26.36%–40.32%，8–12 s 为 17.87%–32.66%，全部超过 10% 要求。
这说明位置恢复收益保留，但不能抵消另一个窗口的速度失败。
相对更早的旧回退，18 条降载配对的 7–8 s 位置误差反而全部增加 0.025552–0.186705 mm，
速度误差全部增加 0.088171–0.687726 mm/s，8–10 s 与 8–12 s 的位置误差也都更高。
即使只看已通过配对，+15° 无额外误差、降载 seed 11 的速度余量也仅有 0.041059 mm/s。
因此准确的概括是“高负载恢复改善，降载追赶变差”，不是整体性能提升。
36 条新候选的接触率均为 100%，最高原始法向力 12.647 N，最小保留力矩余量 3.983 N·m；
绝对工程检查通过仍不代表配对代价通过或硬件安全。

旧回退仍为 **34/36**：本轮修复其两个高负载失败，却新增四个降载失败，不能称作净改进。
静止回退的 **3/4**、原测量回归的 **7/8** 与历史首次揭盲失败均保留，不重写。
只有小试包含静止回退的直接对照；其余 32 个配对没有这一方法。
相对更早的旧回退，本候选同时改变了启用时机和保持期恢复方向，因此这批扩展数据
不能把新失败单独归因于可逆项，更没有证实具体的接触动力学原因。

决定是停止本轮推广，不增加调参或补跑来改变已冻结判定。默认固定 6 N、姿态增益 1、
速度误差时间系数 0.05 s 保持不变；候选可通过下方独立实验入口运行，但不接入默认或 C++ 控制链。

### 可复核证据

两份归档都通过完整性检查与独立辅助状态复算。小试的 4 条 5.5 s 前缀、扩展的
36 条 5.5 s 前缀和 12 条 6 s 故障前缀均逐字段逐字节一致，每项覆盖 69 个周期字段。
扩展共复核 648,000 个控制周期；其中重复引用已包含在计数内，不是 648,000 步新物理。
该审计不独立积分整套机械臂动力学。

- [小试 manifest](../results/franka_reversible_recovery_pilot/manifest.json)：4 新运行＋12 引用。
- [扩展 manifest](../results/franka_reversible_recovery_transfer/manifest.json)：32 新运行＋76 引用，绑定小试哈希和同一套 175 文件源码身份。
- [归档回归测试](../tests/test_published_reversible_recovery.py)：禁止启动物理，重算指标并保留四条失败。

## 复现入口

先按[固定环境说明](reproducible_environment.md)安装并激活环境；以下命令在仓库根目录执行。
新运行要求代码已经提交、已跟踪文件没有修改，并实际加载单线程 Haswell OpenBLAS。
输出目录必须不存在，禁止覆盖发布归档。

只读复核本次已发布结果，不运行新物理：

```bash
MUJOCO_GL=disable python -m tools.reversible_recovery.study \
  --audit results/franka_reversible_recovery_transfer
```

预期 `archive_integrity: PASS`、`comparison_status: FAIL`、`default_changed: false`。
下面才是重新执行实验的命令，耗时与只读审计不同：

```bash
export OPENBLAS_CORETYPE=Haswell OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
MUJOCO_GL=disable python -m tools.reversible_recovery.study \
  --scope pilot --output results/local_reversible_pilot_01
MUJOCO_GL=disable python -m tools.reversible_recovery.study \
  --audit results/local_reversible_pilot_01
```

只有小试重算为 `PASS` 后，才允许执行扩展。扩展入口会重新审计小试，而非只相信摘要中的状态。
小试目录需在仓库内，以便归档保存可搬移的相对引用；它和下列新目录都不是已发布归档。

```bash
MUJOCO_GL=disable python -m tools.reversible_recovery.study \
  --scope transfer --pilot-reference results/local_reversible_pilot_01 \
  --output results/local_reversible_transfer_01
```

[独立状态复算](../tools/reversible_recovery/audit.py)、
[协议与执行入口](../tools/reversible_recovery/study.py)。手算练习见

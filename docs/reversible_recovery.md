# 换向恢复：有入口上限的可逆回退

本页记录一个公开开发试验。运行前先固定规则和门槛；默认固定 6 N、姿态增益 1、
速度误差时间系数 0.05 s 均不变。六轴项目和 BC/PPO 不在本轮范围内。

## 要检验的机制

[上一轮静止回退](stationary_recovery_pilot.md)通过 3/4，整体仍为 `FAIL`。
它把回退推迟到目标静止，两个高负载种子都改善，但 seed 29 仍超原代价上限。
控制器小例子还显示，法向力的短时峰值会给只降不升的系数留下记忆。

这里的系数 $\mu$ 是误差驱动的等效补偿状态，不能直接解释为辨识出的材料摩擦系数。
目标静止时没有切向运动激励，法向力恢复也不能证明材料摩擦变大。
本轮检验的是内部限幅状态的恢复策略，不增加摩擦观测器。

## 唯一算法改动

进入一次有效接触下的目标静止阶段时，记录当时的 $\mu$ 为上限 $\mu_h$。
保持期间使用

$$
\mu^*_k=\min\left(\mu_h,\frac{B_k}{F_{n,k}}\right),\qquad
\mu_{k+1}=\mu_k+\operatorname{clip}
\left(\mu^*_k-\mu_k,-r_\mu\Delta t,r_\mu\Delta t\right).
$$

$B_k$ 是本拍补偿预算，$F_{n,k}>1$ N 是修正法向力。
速率 $r_\mu=0.3$/s 沿用原值，系数不高于本次保持入口值，也不越过原绝对范围。
没有新调参项。若整个保持阶段的法向力和预算均不变，该规则与旧静止回退应给出相同结果。

目标切向速度不超过 $10^{-12}$ m/s 才视作数值零。缺少有效测量包或力矩投影拒绝更新时，
只冻结本次更新，不重新记录入口上限。目标恢复运动、接触失效或控制器重置时清除入口记录。
控制器不读取仿真时间、运动阶段标签或真实摩擦参数。

原运动学习律、50 ms 运动确认、20 N/s 补偿力变化率以及 6–8 N 调度均保持不变。
本协议固定运动更新阈值为 0.005 m/s，高于数值零阈值；保持期间父类学习更新因此关闭。
本文不把这一性质推广到任意自定义更新阈值。
这仍是限幅回退候选，未采用为默认控制器，也未完成 C++ 移植。

## 执行前固定的范围

先运行 −15°、无额外误差下的降载／恒定高负载两种场景，每种使用种子 11、29。
新候选执行 4 次；原调度、旧回退和上一轮静止回退共 12 条轨迹原位引用。
16 条方法轨迹只对应两个物理场景，不是 16 个独立场景。

主要门槛继续按新候选对原调度逐例比较：降载的 8–10 s 和 8–12 s 位置 RMSE 各降低
至少 10%；其余窗口位置增量不超过 0.1 mm；各窗口速度误差增量不超过 0.5 mm/s。
原法向力、姿态、峰值和绝对工程门槛不变。
另外要求两个高负载种子的 7–8 s 位置、速度 RMSE 都严格低于上一轮静止回退。
不能用平均改善覆盖某个配对失败。

只有小试完整通过，才执行已固定的扩展矩阵：表面方向 −15°／0°／15°，
降载／恒定高负载，原有三种误差配置，以及种子 11、29，共 36 个配对。
其中 4 条新候选沿用小试轨迹，仅新增其余 32 条；另外引用 72 条旧方法轨迹，
总计评价 108 条。扩展矩阵仍不包含新载荷、俯仰、缺包组合或真机实验。

新候选对原调度在 5.5 s 前所有逐拍字段必须逐字节相同。
扩展时，幅值误差与对应无幅值误差的候选还须通过 6 s 前的输入错误前缀检查。
复算器独立重建辅助状态方程，不宣称独立复现整个名义控制器或机械臂动力学。

## 复现入口

先按[固定环境说明](reproducible_environment.md)安装并激活环境；以下命令在仓库根目录执行。
新运行要求代码已经提交、已跟踪文件没有修改，并实际加载单线程 Haswell OpenBLAS。
输出目录必须不存在，禁止覆盖发布归档。

```bash
export OPENBLAS_CORETYPE=Haswell OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
MUJOCO_GL=disable python -m tools.reversible_recovery.study \
  --scope pilot --output results/local_reversible_pilot_01
MUJOCO_GL=disable python -m tools.reversible_recovery.study \
  --audit results/local_reversible_pilot_01
```

只有小试重算为 `PASS` 后，才允许执行扩展。扩展入口会重新审计小试，而非只相信摘要中的状态。
小试目录需在仓库内，以便归档保存可搬移的相对引用；它和下列新目录都不是已发布归档。

```bash
MUJOCO_GL=disable python -m tools.reversible_recovery.study \
  --scope transfer --pilot-reference results/local_reversible_pilot_01 \
  --output results/local_reversible_transfer_01
```

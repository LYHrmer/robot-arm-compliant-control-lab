# 跨表面方向的换向与组合误差回归

## 本轮结论

36 次运行全部完成，整体工程检查通过 36/36，阶段检查通过 142/144。
新增 −15°、0° 的 96 个阶段检查全部通过；两条失败都是原 +15°、原增益下的
`reverse_ramp` 姿态增量超限，分别来自固定前馈和在线方法，没有删去。
新增益的三个方向共 72 个阶段检查全部通过。

+15° 的 12 个整体结果、48 个阶段结果和 12 份紧凑轨迹与旧归档复现，最大差值为 0。
这说明新方向是在同一控制实现和同一误差协议下比较，而非顺便更换了控制器。

下表的姿态增量只指停顿换向的 7–8 s，相对**同增益的无补偿基线**计算；通过数则包括
该方向两个工况的全部 8 个阶段。单位为度。

| 表面 yaw | 在线姿态增量，原增益 | 在线姿态增量，新增益 | 在线阶段通过：原 → 新 |
|---|---:|---:|---|
| −15° | 0.00483 | 0.01456 | 8/8 → 8/8 |
| 0° | 0.07213 | 0.05206 | 8/8 → 8/8 |
| +15° | 0.13685 | 0.08723 | 7/8 → 8/8 |

同一个增益变化在不同方向上的相对代价并不一致。−15° 的姿态配对增量反而增加，
只是两套增益都在 0.1° 门槛以内。因此不能把 +15° 的效果直接推广成所有方向均受益。

### 跟踪代价和仍未解决的问题

对在线方法的六个方向／工况配对，新增益全部降低全程姿态误差，也全部增加全程切向
位置和速度误差。按这六次运行的均值计算：

| 在线全程指标 | 原增益 | 新增益 | 均值变化 |
|---|---:|---:|---:|
| 姿态 RMSE [°] | 0.38657 | 0.20816 | −46.15% |
| 切向位置 RMSE [mm] | 1.71915 | 1.74671 | +1.60% |
| 切向速度误差 RMS [mm/s] | 3.30006 | 3.48818 | +5.70% |

各配对的位置增量为 0.01086–0.05044 mm，速度增量为 0.1340–0.2595 mm/s。
这说的是全程评价窗口，不是每一个阶段都退化，也不能将速度 RMS 当作频谱上的振荡结论。
在线方法在两套增益下的全部 12 个配对运行中，切向 RMSE 仍低于同配置固定前馈。

组合误差的 8–12 s 后段仍有 3.255–3.333 mm 的切向 RMSE。两套增益、三个方向都存在
这个精度局限，并未因工程门槛通过而消失。`tangent_recovery_status=recovered` 只表示
8 s 后曾有一个 0.25 s 窗口达到 3 mm 阈值，不表示后续一直达标；原协议也没有把
“后段切向 RMSE ≤3 mm”定义成阶段 gate。这里不事后修改通过数，也不把残余误差隐藏掉。

所有运行的评价接触率为 100%，完整轨迹原始峰值力不超过 12.6593 N，无执行器裁剪或
力矩投影缩放，全部周期的最小预留力矩余量为 4.4040 N·m。这个全局最小值不能替代
逐 case 比较：新增益下，在线方法有五个配对的最小预留余量略减，最大减少 0.02656 N·m。

**本轮不修改控制算法或全局默认值。** 新方向未暴露额外工程门槛失效，已有 +15° 姿态
问题可由可选预设处理，而新增益的跟踪代价仍然存在。保留默认 `s=1` 和可选 `s=2`，
没有根据这一个种子的结果引入方向调度或新的学习策略。若后续任务明确要求组合误差后段
也保持在 3 mm 内，应先单独分析补偿上限与残余误差，再决定控制改动。

后续[12 次单因素诊断](combined_residual_diagnosis.md)已检查这条残差：区分了补偿幅值限制
与力矩裁剪，并保留移除偏置后切向误差反而增大的结果。本页的原通过数与归档不变。

## 运行前固定的协议

本轮只检验已有控制器，不调整参数。把原 12 秒误差实验的两个工况转移到其他表面方向，
用于判断姿态增益的收益和代价是否随几何配置变化。它不扩展工具质量、目标 pitch/roll，
也不增加新的 90° 轨迹转弯。下述矩阵、门槛和完整轨迹选择在运行前确定。

| 因素 | 本轮取值 |
|---|---|
| 真实墙面和任务 yaw | −15°、0°、+15° |
| 工况 | `stop_hold_reverse`、`modest_combined` |
| 方法 | `baseline`、`friction`、`online` |
| 旋转增益比例 | 1、2；所有方法采用同一比例 |
| 噪声种子 | 预选 11，一个种子，不代表噪声鲁棒性 |

合计 36 次运行。时长 12 s，评价从 1.5 s 开始，采样周期 0.002 s。
工具质量、接触模型、噪声幅值及其他参数沿用原误差实验的 case 16。
组合误差仍包含 0.30→0.60 的摩擦缓变、6 s 起 0.75 N 的法向测量偏置、3° 控制法向
偏差和停顿换向。换向工况保持原 0.45 摩擦系数，不施加额外法向误差。

几何转换同时修改真实墙面和任务方向，组合误差的世界坐标偏置随真实法向旋转；
控制法向相对真实法向的偏差仍为 0° 或 3°。+15° 的原配置直接保留，不经额外数值旋转。
目标工具旋转仍取 home 姿态，不能将这些运行解释为任意目标姿态或未知负载验证。

保留无切向补偿的基线，是为了原样计算相对基线的姿态／力误差门槛。积分方法不属于
本轮矩阵；原积分失败记录保持原样。各方法在相同 yaw、工况、种子和增益下配对。

## 验收与数据边界

沿用原 `online_compensation_experiment` 的整体及阶段统计和门槛：接触率至少 99%，
原始峰值力不超过 35 N，执行器裁剪为零；力 RMSE 相对基线增加不超过 0.2 N，
姿态 RMSE 增加不超过 0.1°。在线方法还要相对同增益的固定前馈满足这两项误差门槛。
阶段峰值采用该阶段数据，整体峰值包含入触全过程，不能混用。

额外单列投影比例和未裁剪请求力矩到物理／预留包络的最小余量。
投影比例大于 `1e-10` 或预留余量小于 `-1e-10` 标记为补充检查失败，不改写原门槛。
切向位置和速度误差保留同 case 的 `s=2 − s=1` 差值，不事后追加允许退化的百分比。

+15° 的 12 个整体结果及其阶段结果必须与已有两份归档复现，数值绝对误差不超过
`1e-10`；字符串、布尔标志和失败列表一致。不能以重新生成同名参考替代这个检查。
−15°、0° 属于新增公开开发覆盖。一个噪声种子的结果不能称为新盲测或全面泛化证据。

所有运行保留原紧凑指标输入，另保留真实／目标位置速度、请求／施加力矩、力矩上下限、
补偿请求向量和真实接触间隙，供独立重算。预选 −15° 在线方法的两工况、两增益，
共四份完整输入轨迹；完整轨迹选择在运行前确定，不按结果好坏挑选。

若新增方向出现失效，先明确工况、阶段、比较对象和触发指标，再决定是否需要算法改动。
若没有新增失效，也会报告跟踪代价；通过工程检查不等于闭环稳定性或真机安全证明。

## 运行与独立核验

安装开发依赖后，在仓库根目录执行；生成目录必须不存在：

```bash
python -m tools.cross_surface_regression --output /tmp/cross-surface-dynamic
python -m tools.audit_cross_surface_regression --audit /tmp/cross-surface-dynamic

# 只核验仓库归档，不重新运行机械臂动力学
python -m tools.audit_cross_surface_regression --audit results/franka_cross_surface_dynamic
```

[生成器](../tools/cross_surface_regression.py)复用现有调度仿真、相位指标及门槛，
[配对模块](../tools/cross_surface_pairs.py)拒绝缺少对应增益或身份不一致的运行。
[独立审计](../tools/audit_cross_surface_regression.py)复用已有独立指标重算函数，另从
原始位置／速度重算切向投影，从请求／施加力矩核对裁剪、物理限值和预留余量。
审计同时检查全部紧凑数据、原始输入、四份完整轨迹与固定参考；修改数据后重新计算
manifest 也不能绕过这些数值和身份检查。这不是外部执行认证。

本轮未改 C++ 控制器，也未新做全矩阵 C++ 回放。完整输入轨迹用于保留可复核的控制输入，
既有 C++ 数值移植证据仍见[原回放说明](cpp_core.md)，不与这 36 次新动力学运行混算。

# BC 输入消融：从离线拟合到闭环跟踪

[首轮 BC](surface_learning_pilot.md)的验证动作误差很小，三个训练种子的开发测试跟踪却分别
只通过 `0/4、4/4、2/4`。保存的 NumPy 模型能够复现训练端的离线误差；学生实际访问
状态上的动作误差明显增大。这次从输入入手，检查网络是否依赖了教师公式不需要的量。

实际训练和全部种子结果见[输入消融归档](../results/franka_surface_bc_transfer/README.md)。

## 教师需要哪些观测

教师通过测得的法向力 `Fn` 和目标切向速度 `vₜ` 计算补偿。默认参数下：

```text
amplitude = min(0.45 × max(Fn, 0), 6 N)
fₜ = amplitude × vₜ / sqrt(||vₜ||² + (0.005 m/s)²)
a_teacher = [0, fₜ₁ / 6 N, fₜ₂ / 6 N]
```

在 49 维标准化观测中，这些量对应索引 `0、10、11`。教师不读取真实摩擦系数，
也不读取仿真评价器里的接触真值。具体实现是
[`friction_teacher_action`](../src/compliant_control_lab/surface_policy.py)。

网络原来还可以看到上一步施加的残差、跟踪误差和关节状态。在教师轨迹中，上一步补偿
通常很接近下一步标签。学生开始产生偏差以后，这种相关关系未必仍然成立。
相关性只能提供线索，需要重新训练后的闭环对照来检查。

## 保留原网络，改变可用输入

| 对照 | 可用输入 | 回答的问题 |
|---|---|---|
| `full49` | 原来的全部 49 维 | 沿用首轮同种子结果，记录未改动的表现 |
| `drop_previous_residual` | 将索引 `14、15、16` 置零 | 去掉上一步残差是否足够 |
| `teacher_inputs` | 只保留 `0、10、11` | 加入教师已知的输入先验，能否可靠学习补偿 |

两种新配置都使用 `49 → 32 → 32 → 3` 的 tanh 网络。隐藏层宽度不变，但允许学习的
输入依赖减少了，因此不能称为“有效容量完全相同”的实验。

设二值掩码为 `m`，训练时使用 `o_masked = o × m`。导出时把掩码合入第一层权重：

```text
W1_export[:, j] = W1_train[:, j] × m[j]
```

运行端仍接收原始 49 维观测，不需要新增预处理分支。每个候选导出后，在完整训练与
验证观测上比较 NumPy 原始输入输出和 PyTorch 屏蔽输入输出，并将被屏蔽输入替换为
`±3` 再检查输出不变。这样能发现“训练时屏蔽了，部署时又读到了”的接口错误。

这一步只改变输入。教师标签、残差限幅及控制器中的滤波和力矩投影都保持原样。

## 怎样选择、怎样报告

新训练继续使用原来的 16 个训练回合，4 个验证回合只用于模型选择。
种子固定为 `11、29、47`；每个网络运行完整 100 epoch，Adam 学习率 `0.001`，
batch 256。每个种子按完整离线验证 MSE 选择 epoch，数值完全相同时保留更早的一轮。
先前的 49 输入对照具有相同初始化种子、训练数据和预算，不重复拟合。

某种输入配置只有在三个种子都通过四个闭环验证任务及原有门槛时，才被接受。
若两种配置都合格，依次比较全部验证回合的平均切向误差、平均法向力误差；完全相同
时按配置名称排序。不会从三个种子里挑一个最好模型来代表整个方法。

六个候选和配置选择记录全部固定后，才运行本轮开发测试。四个开发 case 属于已经公开
使用过的任务域，不能称为新盲测。两种输入配置的所有种子都会报告，包括不达标的结果。

学生状态上的教师动作误差从已保存的验证轨迹重算，仅用于解释结果，不回填训练集，
也不用于重新挑选 epoch。本轮没有混入学生状态采样；如果还需要补数据，应另立实验。

若去掉历史残差有效，只能说明这种输入处理在本次训练与任务域中改善了结果。
若只有教师输入配置有效，说明更强的输入先验有帮助。两种结果都不足以证明某个单独
通道是所有失败的唯一原因，也不能推断未见表面上的泛化能力。

## 验证集上观察到了什么

两种新配置的三个训练种子都通过了四个验证任务，接触率均为 100%。
三个种子重复运行相同四个 case，验证集仍只有两个物理任务组，不能当作十二个不同场景。
`drop_previous_residual` 的十二回合平均切向 RMSE 为 `5.052 mm`，
`teacher_inputs` 为 `5.674 mm`。按冻结规则选择前者，三个种子全部保留。

下面是在学生实际访问的验证状态上，重新计算教师标签得到的动作 MSE。
这些状态没有用于训练。

| 训练 seed | 原 49 输入 | 去掉上一步残差 | 只保留教师输入 |
|---:|---:|---:|---:|
| 11 | 0.361475 | 0.003550 | 0.002551 |
| 29 | 0.090741 | 0.002734 | 0.004390 |
| 47 | 0.344482 | 0.002970 | 0.004528 |

去掉历史残差后，离线验证 MSE 反而从约 `0.0012–0.0016` 升到 `0.0032–0.0040`，
但学生状态上的误差和闭环跟踪均改善了。只看教师数据上的拟合成绩，会错过这个变化。
这组对照支持保留历史输入消融，尚不能区分三个被移除通道分别产生了多大影响。

已选中的历史残差屏蔽方案在开发测试中，三个种子均通过 `4/4`，平均切向误差分别为
`2.818、2.825、2.781 mm`；首轮 49 输入对照为 `14.787、3.801、8.721 mm`。
同 case 的解析摩擦前馈仍更准确，平均为 `2.403 mm`。目前的收益是 BC 跟踪变得可靠，
并没有证明它优于解析控制。

## 复现入口

先按[准备数据说明](surface_learning.md)生成完整 v2 数据，再运行
[首轮学习试验](surface_learning_pilot.md#本地复现)，保留其原始 plan SHA。
下面的 `PARENT_PLAN_SHA` 和 `TRANSFER_PLAN_SHA` 都需要替换为相应冻结命令输出的值。

```bash
python -m tools.surface_bc_transfer freeze \
  --parent dist/surface-learning-pilot-v1 \
  --dataset dist/surface-preparation-v2/dataset \
  --benchmark dist/surface-preparation-v2/benchmark \
  --output dist/surface-bc-transfer-v1 \
  --expected-parent-plan-sha256 PARENT_PLAN_SHA

python -m tools.surface_bc_transfer run \
  --parent dist/surface-learning-pilot-v1 \
  --dataset dist/surface-preparation-v2/dataset \
  --benchmark dist/surface-preparation-v2/benchmark \
  --output dist/surface-bc-transfer-v1 \
  --expected-plan-sha256 TRANSFER_PLAN_SHA
```

`train` 和 `validate` 子命令可配合 `--arm`、`--seed` 分别执行已声明的训练或验证任务。
后续 `run` 只复用身份校验通过的完整产物；已完成的整轮实验拒绝重复运行开发测试。
失败训练保留 `FAILED` 记录，不能通过覆盖目录把失败抹掉。

公开副本包含全部候选和训练曲线，另附两份完整物理轨迹。下面的命令检查文件哈希、
重算配置选择及两份轨迹的指标，不重新积分动力学：

```bash
python -m tools.publish_surface_bc_transfer --audit results/franka_surface_bc_transfer
```

## BC 完成以后再接 RL

BC 输出的是自适应导纳上需要补充的摩擦力。RL 的名义控制器已经包含摩擦前馈，两者的
动作含义不同。直接复制 BC 输出层可能导致重复补偿。

后续候选方案只迁移 BC 的两个隐藏层，RL 输出层重新置零，价值网络保持相同种子的
全新初始化。第零回合确定性动作应严格等于零，再检验相同训练预算下这种表示是否
有帮助。RL 训练需要等 BC 验证结束后单独冻结方案，不能把初始化检查当作性能结论。
